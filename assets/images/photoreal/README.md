# Photorealism pass

Six separate image edits, in website order. Original assets remain in the showcase and process folders.

1. 01-apparel-hero.webp — layered apparel hero
2. 02-screen-printing.webp — screen-print close-up
3. 03-embroidery.webp — embroidered polo close-up
4. 04-dtf-printing.webp — photographic portrait transfer on a shirt
5. 05-consultation.webp — workshop consultation
6. 06-quality-control.webp — finished-garment inspection

Created with the built-in image generation tool using each original as a strict composition reference, with shared references for textile and workshop consistency. The pass targets natural fibers, skin, ink, thread, light and depth without redesigning the scenes. Optimized WebP versions preserve the original aspect ratios.

These remain generated illustrative images, not documentary evidence of real customers, completed orders or the studio's premises. The original logo and interface artwork were retained.
