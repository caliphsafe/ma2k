# MA2K showcase assets

Brand concept imagery created from the approved MA2K Impression Apparel Showcase reference on 2026-10-09. These are illustrative apparel concepts, not documentary photographs of completed client orders. The original image assets and archived site are retained.

- apparel-hero.webp: layered forest hoodie, cream printed tee and embroidered cap.
- screen-printing.webp: cream screen-print concept on black cotton.
- embroidery.webp: gold stitch concept on forest green polo.
- dtf-printing.webp: full-color illustrated portrait transfer concept.
- logo-reference.webp: reference-matched logo in forest, terracotta, gold, cream and black, with transparent background.
- paper-grain.svg: lightweight procedural paper texture.

Raster images were generated with the built-in image generation tool and converted to optimized WebP files for website use.
